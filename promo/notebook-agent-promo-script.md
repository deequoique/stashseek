# Notebook Agent 演示宣传视频脚本

## 基本设定

- 片名：**Notebook Agent｜让看过的内容，真正成为你的知识**
- 时长：约 120 秒
- 画幅：仅 16:9，1920×1080
- 风格：温暖纸张质感 + 深色信息面板；主色沿用项目的米白、墨黑、砖红和绿色
- 音乐：轻快但克制的电子氛围，约 100–110 BPM；关键切换加入轻微 whoosh / click
- 旁白：中文，按普通字幕语速约 1.25 倍设计；可信、清晰，不要“夸张科技腔”

## 片尾小字（建议保留 2 秒）

> 当前完整导入以 YouTube 为主；NTULearn/Kaltura 通过浏览器伴侣提交字幕。Bilibili 目前仅支持链接识别，尚未实现内容导入；片头的小红书和 TikTok 图标仅表示内容分散场景。

## 制作时需要准备的素材

1. `web/src/assets/notebook-agent-logo.png`：片头、片尾和角标 Logo。
2. Telegram 对话演示：保存链接、自然语言问题、证据回答和 `/link web`；使用真实 Agent 安全文案。
3. 一条演示用 YouTube 链接和三条真实时间戳证据。建议沿用 Showcase 页面里的示例，但需确认展示权限。
4. 浏览器伴侣演示：当前 YouTube 或 NTULearn/Kaltura 页面、插件弹窗和“保存当前视频”状态。

## 制作方式

### Remotion

用 React/TypeScript 做 9 个场景，直接读取 Logo、字幕和演示数据，最后渲染横屏 MP4。动画节奏、字体和颜色都能版本化管理。


## 导出建议

- 主版：H.264 MP4，1920×1080，30fps，码率 8–12 Mbps，时长约 120 秒。
- 文件名建议：`notebook-agent-demo-promo-zh-v2.mp4`。
