# 实现多模态候选验证 Agent Tool

## 目标
把多模态大模型包装为受限的 `inspect_media` tool，让 Agent 对已召回的少量图片/视频候选进行验证、OCR、动作或关系判断，而不是开放式扫描媒体库。

## 验收
- [ ] tool 只接受当前 retrieval run 暴露的 media_id。
- [ ] 服务端强制候选数、超时、租户权限、删除状态和调用预算。
- [ ] 返回结构化相关性、置信度、证据、OCR/对象/动作和时间范围。
- [ ] 以 media hash、问题、模型和 prompt 版本缓存结果。
- [ ] 简单检索不无条件调用；复杂视觉问题有确定性路由测试。
