# 视频发现识别模型基准计划

> **历史文档（已被取代，2026-08-26）**：本文件保留原“全候选/全 12 视频”基准执行计划，仅用于 provenance 与回归参考。该计划已由 `prd.md`、`design.md` 和 `public-benchmark-evidence-map-2026-08-26.md` 取代；不得据此授权 provider 调用，也不得据此执行固定 3 次/全候选运行。

## 目的

用公开 YouTube/Bilibili 真实样本选择首期托管 ASR、托管多模态视觉和托管 OCR 默认实现，并保留本地 OCR 质量/降级对照。模型必须先通过搜索召回、时间段定位和结构化协议质量门，再比较延迟与费用。

## 执行前冻结

运行候选前冻结公开样本、查询、正确视频、可接受时间区间、所需模态、关键术语、字幕分组、运行次数和质量门。禁止根据某个供应商的输出事后改写真值或只保留表现好的样本。

## 样本矩阵

- 平台：YouTube、Bilibili。
- 语言：英语、普通话、中英混合。
- 内容：课程/访谈、幻灯片、软件录屏、图表、一般实景、混合内容。
- 音频：清晰、噪声、快速语速、专业术语、长静音。
- 屏幕文字：中英文、大字、小字、代码、按钮、数字、重复幻灯片。
- 字幕：完整、局部缺口、片头/零散、无字幕。

## 候选约束

- ASR 原生或通过稳定协议返回片段/词级时间戳，并覆盖英语、中文和混合语言。
- 视觉支持多图输入、结构化 JSON 和有界分辨率。
- OCR 无论托管或本地都输出文字、坐标和置信度，并覆盖中英文/代码；托管候选必须接受图片 bytes，不能要求暴露视频或签名 URL。
- 执行时从官方文档核验模型、限制、数据处理和价格，记录查询日期。

## 主要质量门

- 正确视频 Top-K 命中率。
- Segment 与可接受时间范围的命中/重叠。
- ASR/OCR 关键术语召回。
- JSON Schema 一次通过率。
- 意图路由漏识别/不必要识别。
- 重复运行一致性。

门槛数值在 dry run 前冻结。任何主要质量门未通过的候选直接淘汰，低费用不能补偿。

## 次级比较与交付

比较处理耗时、失败/重试、音频分钟/代表帧调用量、估算费用、本地 CPU/内存和运维复杂度。交付 catalog/真值、指标矩阵、胜出默认值、淘汰原因、脱敏 fixtures、失败矩阵，以及对采样数量、字幕质量门和 Segment 切分的实测修订。

## 安全与清理

只使用用户选定的 12 个公开视频，并显式记录其中缺少开放许可证据的权利不确定性；不上传私有课程媒体。每个 provider 只接收冻结的短音频窗口或代表帧，日志不含媒体、字幕、帧、查询真值、签名 URL 或供应商响应体。临时媒体和派生帧按 run 清理，报告只保存必要数值、稳定错误和脱敏标识。
