# 实施计划：Notebook Agent 横屏 Remotion 宣传视频

## 1. 工程初始化

- 创建 `promo/remotion/` 独立 TypeScript 工程和最小 Remotion 依赖。
- 配置 1920×1080、30fps 的横屏 Composition、开发预览和 render 脚本。
- 复制/链接项目 Logo，并建立资产目录与 README。

## 2. 视觉基础设施

- 创建颜色、间距、圆角、阴影和字体常量。
- 实现 Logo、标题、字幕、视频卡片、流程节点、聊天气泡和证据卡片组件。
- 添加通用淡入、滑入、堆叠和打字机动画 helper。

## 3. 场景实现

按设计文档顺序实现 9 个场景，先使用纯代码图形和静态演示数据保证无外部素材也能预览；再接入 Logo、截图/录屏和可选音频。

## 4. 时间轴与字幕

- 将 2 分钟中文旁白脚本整理为结构化数据。
- 为每个场景设置明确起止帧，合成全局字幕和可选旁白。
- 检查转场边界，避免场景重叠、黑帧和文字出界。

## 5. 验证

- 在 Studio 中检查整片节奏、文字可读性和 Logo 清晰度。
- 运行工程提供的 `pnpm typecheck`、`pnpm lint`。
- 渲染低分辨率预览后再渲染 1920×1080 最终 MP4。
- 使用系统播放器确认文件可播放、时长约 120 秒且音视频轨道符合预期。

## 6. 交付

- 提供 `promo/remotion/README.md`，说明安装、预览、替换资产、加入旁白和最终渲染命令。
- 保留可重复渲染的源代码、字幕数据和最终 MP4 路径。
