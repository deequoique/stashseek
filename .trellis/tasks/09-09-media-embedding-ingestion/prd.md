# 实现图片视频摄入与 WeMM Embedding

## 目标
在异步摄入链路中生成图片和有界视频片段的 WeMM 向量，支持幂等、重试、失败恢复和媒体清理，不阻塞现有文本摄入。

## 验收
- [ ] 图片可从对象存储引用生成向量并写入媒体资产。
- [ ] 视频按配置执行抽帧/片段化，保留时间范围和可跳转 provenance。
- [ ] 重复任务不重复写入或计费；失败可重试且有稳定状态。
- [ ] 关闭 feature flag 时旧文本摄入结果不变。

## 执行边界
- 官方 API 核对及 lazy adapter 不属于 benchmark，仍需完成。
- 新 WeMM 空间使用明确模型/版本/支持的维度，不能沿用旧智谱 1536 维或直接比较两个模型的向量。
- 无数据库阶段只能交付契约及 fake 驱动实现；真实持久化摄入需要最后的数据库子任务，不得提前标记本子任务整体完成。
