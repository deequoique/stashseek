# 使用插件工作区

这页讲的是已经安装并配置好的浏览器插件工作区如何使用：登录、保存视频、搜索、查看字幕
依据和管理条目。部署者请先看[部署通用生产环境](deploy-production.md)；插件只展示
当前登录租户的资料，不是公开的视频搜索站。

## 1. 登录

从扩展弹窗打开插件工作区，确认插件保存的 API origin 属于你的部署。生产邮件登录使用一次性 6 位验证码；保留的渠道登录可能显示 Telegram 或微信批准流程。

安全地完成登录：

1. 确认插件显示的 API origin 是预期的 HTTPS 地址，并且没有把 token 放入 query 参数。
2. 输入自己的邮箱或按页面提示发起渠道登录。
3. 只在受信任的邮件、Telegram 或微信会话中查看验证码/批准请求。
4. 在插件工作区完成验证，进入“我的视频资料库”。

生产 Web 登录必须由部署者配置 `WEB_AUTH_ENABLED=true`、精确的
`WEB_PUBLIC_ORIGIN`、至少 32 个字符的 `WEB_AUTH_SECRET`、`WEB_COOKIE_SECURE=true`
和邮件 provider；这些是部署条件，不要在浏览器端绕过。完整变量说明见
[环境变量参考](../reference/configuration.md)。

不要把验证码、session cookie、CSRF cookie 或浏览器开发者工具中的请求头复制到
聊天、Issue、截图或日志。若怀疑账号或设备泄露，先退出并联系部署者撤销 session。

## 2. 添加视频

在资料库点击“添加视频”，一次最多输入 10 个视频链接或 BV 号。输入框支持按 Enter
把输入变成可移除的标签，也支持一次混合粘贴多行；可选填写“备注”或选择一个收藏夹标签。

服务器端添加支持：

- YouTube 普通视频链接；
- Bilibili 普通视频链接，或直接输入完整 BV 号，例如 `BV1xx411c7mD`；
- 对当前账号可访问、且服务端能够取得字幕的内容。

直接输入 BV 号与输入对应完整链接会识别为同一个视频。BV 后缀区分大小写，请原样
复制。也可以直接粘贴 B 站的整段分享内容，例如：

```text
【一个小改装作坊，如何凭一台”红猪“改写奔驰赛车历史？】 https://www.bilibili.com/video/BV15pao6iEZo/?share_source=copy_web
```

系统会去掉标题等文字、提取实际视频链接；标题和链接分成两行也可以。保存前会将
有效链接归一化，去掉分享追踪参数。多个分享可以一起粘贴，提取后仍最多添加 10 个
视频。只有文字和零散 BV 片段、没有完整视频链接的内容不会被当作分享链接识别。

提交后不要反复点击提交。服务会先返回 `排队中`，条目再经过 `整理中`，有
可用字幕（或服务器开启语音转写后转写出的正文）并完成索引后才变为 `可检索`。同一个视频已经存在时，页面会提示已有条目。
配额、队列不可用和来源暂不支持会显示不同的错误状态；按提示处理，不要把失败
状态当作已完成的知识导入。

服务器无法直接读取字幕的 YouTube 页面，应使用[浏览器伴侣](use-browser-companion.md)。
服务器开启语音转写（`ASR_ENABLED`）时，没有字幕的 YouTube/Bilibili 条目会自动转写，进度显示“语音转写中”；
没有开启、平台不支持或转写失败时，条目会写明原因并保留链接，可以点“重新整理”再试，也可以先按标题或备注查找。
Bilibili 字幕需要登录才能读取时，服务器不会改走转写：先登录 Bilibili，再在视频页用插件重新收藏。

### 选择 B 站分 P

“添加视频”中显示“选择 B 站分 P”时，可以按下面的方式保存课程等多 P 视频：

1. 切换到“选择 B 站分 P”，输入完整 BV 号或 B 站视频链接。指定的 `?p=2` 等
   分 P 参数会保留；预览后仍需亲自勾选，不会默认导入 P1 或全部分 P。
2. 点击“预览分 P”，查看父视频标题、各 P 标题和时长；需要时翻页。预览不会
   保存视频。重新预览会按页面提示清空原选择。
3. 勾选需要的分 P，查看“已选 N / 10 个分 P”。每个分 P 独立占一项；例如
   P1 和 P2 是两项。可选填写备注或指定资料库收藏夹标签，再确认添加。
4. 查看逐项结果。“已添加，等待整理”表示已受理；字幕读取和索引仍在后台进行。

普通 BV/分享链接添加保留原来的 P1 行为。如果资料库已有无法确认对应 CID 的
旧记录，新界面会提示本次将另外保存独立分 P。只有逐项勾选“我了解并同意……
单独保存”才会创建重叠的新记录；也可以取消选择。原条目、备注、字幕和历史记录
都保留。已能证明是同一个分 P 的记录会按已有条目处理。

预览选择凭据在 30 分钟后过期，需要重新预览。可读取分 P 列表不代表有可用字幕；
缺少字幕或来源发生变化时会明确显示需要处理或来源不可用。不要把新占据某个 P
位置的视频当成原来选中的内容。已验证分 P 的来源、章节、字幕与 AI 引用链接由
服务端定位到该分 P 的当前位置和对应时间点。

### 从公开 B 站收藏夹选择

显示“导入公开 B 站收藏夹”入口的版本支持粘贴公开收藏夹地址，例如
`https://space.bilibili.com/400561576/favlist?fid=4157547776&ftype=create`，或
`https://www.bilibili.com/medialist/detail/ml4157547776`。

先预览列表，再展开需要的视频并勾选具体分 P。展开不自动选择，未展开的视频不会
被导入。收藏夹每页显示最多 20 个父视频，所选分 P 合计仍最多 10 项；翻页期间
保留本次明确选择。批量选择只作用于页面标出的已加载范围，不代表整个收藏夹。
页面会标明预览上限，不会在后台遍历或持续同步整个收藏夹。

私密、失效或非视频条目不能导入；读取失败也不会显示成空收藏夹。B 站风控或请求
过于频繁时会提示稍后再试，不需要提供 Cookie、SESSDATA 或 B 站账号凭据。
现有添加配额保持不变。

关闭窗口、刷新或退出登录会清除尚未提交的选择；已经受理的条目继续整理。如果
网络中断导致“未能确认本次结果”，先使用页面提供的重试/查看资料库操作，不要
连续建立新一轮导入。收藏夹名称不会自动覆盖资料库中已有条目的标签或备注。

部署说明：分 P 与收藏夹入口需要包含这些功能的新版服务和相应来源字段迁移。
本次本地代码修改尚不等于线上发布；生产迁移、部署与真实收藏夹导入均须另行授权。
只读演示仍不能添加视频。

## 3. 浏览、筛选和搜索

资料库页面按区域展示“可阅读”和“正在整理”的条目。你可以：

- 在搜索框中输入标题、作者或备注；输入时会出现本地建议，选择建议后再请求服务器；
- 按 `可检索`、`排队中`、`整理中`、`需要处理`、`整理失败` 或 `已归档` 筛选；没整理完的条目会写明原因，并标出“正文不可检索”，仍然可以按标题、作者或备注找到；
- 按最近添加、最早添加或标题排序；
- 点击收藏夹标签，只显示该标签对应的条目。

搜索只在自己的资料库内执行。它不会查询全网，也不会因为记得某个标题就访问另一个
租户的条目。

## 4. 查看视频和依据

点击条目进入详情页，先检查标题、作者、来源和整理状态，再打开字幕/Transcript。
完成整理的内容会以分页方式显示字幕片段和时间点；从时间戳链接返回原视频时，仍会
跳回对应位置。标题、字幕内容和来源状态由服务端保存，不要根据封面或模型摘要推断
未显示的章节。

在资料库点击“AI 智能检索”可以询问已经保存的视频。高质量回答会附带原文依据、
来源标题和可跳转的时间点；如果没有足够证据，界面应显示无依据/暂不可用，而不是
编造来源。回答只使用当前租户的 ready 条目。

## 5. 管理条目

在详情页或条目操作菜单中：

- 更新备注或收藏夹标签；
- 归档暂时不想看的内容；
- 从“已归档”筛选中恢复条目；
- 对整理失败的条目执行重试。

归档不会把内容变成另一个用户可见；重试也不会改变来源权限。后台处理中时不要
重复新增同一链接，先等待原 dispatch 的状态更新。

## 6. 退出与设备管理

使用插件账号菜单退出登录。若使用浏览器伴侣，打开“浏览器伴侣”页面查看已连接设备，
不再使用的设备点击“断开连接”；这会撤销该设备的 capture grant，但不会删除资料库
条目。浏览器伴侣的具体操作见[使用浏览器伴侣](use-browser-companion.md)。
